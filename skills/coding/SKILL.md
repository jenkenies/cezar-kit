# 编码

- 先完整阅读设计文档:任务描述中指定了文件名则用指定的,否则取当前 worktree 内

- 再读仓库根目录下的规范文件——**以仓库实际存在的为准**:

- 不引入新依赖;确有必要 → 停止并说明理由
- 按设计文档的实施步骤推进,每完成一步在总结中简述改动
